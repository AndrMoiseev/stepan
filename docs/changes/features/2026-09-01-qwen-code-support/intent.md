# Поддержка Qwen Code

## Problem and context

Stepan позволяет пройти `/feature` flow с Codex и Claude Code-совместимыми агентами, но не предлагает Qwen Code как самостоятельный вариант. Пользователь не может явно выбрать официальный Qwen Code или совместимый с ним сторонний CLI и получить тот же поддерживаемый опыт без подмены его режимом Claude, совместимость с которым не подтверждена.

## Observable outcome

Пользователь может явно выбрать Qwen Code и пройти весь `/feature` flow с теми же этапами, решениями пользователя, границами безопасности и явным поведением при ошибках, что и с уже поддерживаемыми агентами. Этот результат доступен на Windows/amd64 и Apple Silicon macOS как для официального Qwen Code, так и для стороннего CLI, совместимого с ним по протоколу.

## Scope

- Qwen Code как отдельный, явно выбираемый агентский runtime.
- Полный пользовательский паритет существующего `/feature` flow.
- Официальный Qwen Code и сторонние CLI, совместимые с ним по протоколу независимо от имени и бренда.
- Поддержка Windows/amd64 и Apple Silicon macOS.
- Понятное пользователю проявление несовместимости или отказа агента без скрытого продолжения flow.

## Exclusions

- Использование режима Claude как неподтверждённого пути запуска Qwen Code.
- Замена Codex как агента по умолчанию или автоматический выбор Qwen Code.
- Установка, авторизация и первоначальная настройка Qwen Code или стороннего CLI силами Stepan.
- Обещание совместимости стороннему CLI только на основании его имени, бренда или заявления поставщика.
- Поддержка Linux, Intel Mac, signing или notarization.

## Material constraints

- Qwen Code не должен ослаблять действующие границы Stepan: проект доступен агенту только для чтения, запись разрешена лишь в назначенный корень текущего артефакта, а настройки и внешние возможности агента не могут незаметно расширять эти права.
- Codex остаётся агентом по умолчанию; Qwen Code используется только после явного выбора пользователя.
- Stepan не проверяет и не ограничивает версию Qwen Code или совместимого стороннего CLI. Совместимость определяется фактическим протокольным поведением, а несовместимость проявляется как явный отказ.
- Пользователь заранее устанавливает, авторизует и настраивает выбранный CLI.
