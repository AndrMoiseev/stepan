# Проверка nessy-adapter-auth

Дата: 2026-09-08. Локальная платформа: Windows/amd64, Go 1.26.5.

## Выполнено

| Проверка | Результат |
| --- | --- |
| `go test ./...` | PASS |
| Финальные тесты stderr/Wait/assignment после дополнения fake-вывода токеном | PASS |
| `go build -o stepan.exe ./cmd/stepan` | PASS |
| macOS/arm64 cross-build с `CGO_ENABLED=0` | PASS, только компиляция |
| Компиляция `nessy_real_cli` тестов Windows | PASS |
| Компиляция `nessy_real_cli` тестов darwin/arm64 | PASS, только компиляция |
| Синтаксис PowerShell runner и `bash -n` Bash runner | PASS |
| Windows runner без Nessy в PATH | Ожидаемый безопасный отказ `executable_not_found` |
| Tagged harness с fake Nessy в PATH, временным пустым home и конфликтующим environment-токеном | Ожидаемый безопасный отказ `configuration`, ни один агент не запущен |
| `openspec validate nessy-adapter-auth --strict` | PASS |
| `git diff --check` | PASS |

Проверки покрывают фиксированный PATH executable, отказ от старого провайдера и
override, загрузку только домашнего файла, ошибки JSON/поля/чтения, независимость
Codex/Claude, снимок настроек, окружение нескольких процессов, отсутствие токена
в argv/промптах, сокрытие stderr и отказ от ACP-ответов с секретом до публикации
в flow. Существующие проверки ACP, инструментов и lifecycle сохранены.

В ходе работы были исправлены ошибки адаптации тестов (старые сигнатуры и
ожидания executable), а также проверка пустого значения окружения в тесте
секретов. Итоговые результаты выше относятся к исправленной версии.

## Не выполнено

- Задача 4.3: подтверждение внешних флагов и `QWEN_CODE_*` на целевой версии
  Nessy. Команда `nessy` не найдена в PATH; версия и поддержка не установлены.
- Задача 5.3: реальная Windows-приёмка. Кроме CLI, отсутствует домашний
  `~/.stepan/settings.json`. Токен не запрашивался и не создавался автоматически.
- Задача 5.4: нативная проверка и реальная приёмка на физическом Apple Silicon
  Mac. Такой стенд в текущей сессии недоступен.

Эти три задачи остаются открытыми. Cross-build, fake CLI и ожидаемые отказы
runner не являются доказательствами успешной реальной приёмки. Следующие
действия описаны в [manual-test-plan.md](manual-test-plan.md).
