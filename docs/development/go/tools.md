# Инструменты Go

Читайте при настройке окружения, форматировании или выборе средств тестирования. Версии закреплены в `go.mod` и `go.sum`; команды выполняются из корня репозитория.

## CLI

Инструменты из директивы `tool` доступны через `go tool`, независимо от наличия пользовательского Go bin в PATH:

```powershell
go tool goimports -w path/to/changed.go
go tool gofumpt -w path/to/changed.go
go tool gotests -h
go tool staticcheck ./...
```

Подставляйте конкретные изменённые файлы при форматировании. `gotests` применяйте для заготовок новых тестов, затем задавайте проверяемые ожидания вручную. `staticcheck` уже включён в CI.

Для установки тех же версий как отдельных исполняемых файлов:

```powershell
go install github.com/cweill/gotests/gotests mvdan.cc/gofumpt golang.org/x/tools/cmd/goimports
```

## Библиотеки тестирования

В зависимости добавлены `github.com/stretchr/testify` и `go.uber.org/goleak`. Подключайте нужный пакет в тесте при его применении. Пока библиотека не используется в исходниках, `go mod tidy` может удалить её из зависимостей.

`assert` позволяет продолжить проверки, `require` завершает текущий тест; оба должны получать `t` соответствующего subtest. `goleak.VerifyNone` подходит для изолированного теста без параллельного постороннего фона; для пакета с параллельными тестами рассматривайте `goleak.VerifyTestMain` в существующем или новом `TestMain`.

Команды обязательных тестовых наборов находятся в [AGENTS.md](../../../AGENTS.md).
