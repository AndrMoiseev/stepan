# Спецификации

Каждая спецификация и её производные документы хранятся в отдельном каталоге:

```text
docs/specs/<spec-id>/
  specification.md
  implementation-plan.md
  ...
```

- `specification.md` — авторитетное описание требований и границ.
- `implementation-plan.md` — порядок реализации и проверки.
- Контракты, отчёты и другие документы, полученные при реализации, размещаются рядом и получают короткие предметные имена.
