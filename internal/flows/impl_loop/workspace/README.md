# Управление рабочей копией

`Control` — контракт наблюдения за рабочей копией, сравнения снимков,
выборочного восстановления и получения diff для ревью. `Repository` добавляет
поиск корня и проверки перед новым запуском.

- `git.Control` — рабочая реализация поверх `internal/git` и Git CLI.
  Контрактные тесты и проверки начального состояния запускаются с тегом
  `git_integration`.
- `testfs.New()` — файловая реализация для тестов оркестрации без внешних
  процессов. Наблюдает обычные файлы, сохраняет снимки в памяти и поддерживает
  выборочное восстановление. Не моделирует индекс, ветки, symlink, submodule
  и Git-фильтры. `AssignmentDiff` возвращает фиксированный текст; сценарии,
  которым нужен конкретный diff, используют специализированный fake.

Обе реализации зависят от контракта, но не от пакета `impl_loop`.
Импорт `testfs` в рабочий код запрещён правилами `arch-go.yml`.
Типы снимков и различий пока принадлежат `internal/git`: их также используют
хранилище и другие потребители. Этот модуль не меняет формат сохранённого состояния.
