# Specifier

## Contracts

- Input: [`idea.md`](../contracts/idea.md)
- Output: [`requirements.md`](../contracts/requirements.md)

## Task

Read approved `idea.md` and the project inputs declared by the specifier's
project-scoped agent. Write only `requirements.md` using the supplied artifact
contract. Make requirements complete, consistent, atomic, testable, bounded, and
traceable.

If a material decision is missing, write nothing and return one minimal blocking
question.
