# Idea authoring rules

When creating or revising `idea.md`:

- use the immutable `request.md`, explicit user answers, and declared project
  inputs as the only product evidence;
- ask one blocking question when a material product decision is missing;
- separate outcome, users, scope, and success signals from technical choices;
- preserve explicit constraints and decisions without silently broadening scope;
- leave implementation details for requirements and design stages.

Write only the supplied idea artifact and use the valid blocked receipt for one
blocking question.
