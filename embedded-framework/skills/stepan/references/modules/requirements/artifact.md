# `requirements.md` artifact contract

Keep every required section non-empty. Additional useful sections are allowed.

```text
# Requirements
## Requirements
### REQ-001 — <short name>
Statement: <one atomic requirement>
Verification: <observable check>
## Boundaries and assumptions
```

Give every requirement one unique `REQ-*` ID. Preserve existing IDs during
revision: never renumber an existing requirement or reuse a removed ID.
