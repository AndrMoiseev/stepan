# Idea

## Problem

Подготовка изменений с помощью агентов не имеет единого воспроизводимого flow: решения могут зависеть от истории чата, роли и границы ответственности неясны, а артефакты, ревью и утверждения не образуют устойчивого пакета в репозитории.

## Goal

Определить переносимый SDD flow до начала реализации, который превращает явную идею пользователя в утверждённый пакет `idea → requirements → design → plan`, готовый к реализации.

## Target user

Разработчик или команда, которые готовят изменения в репозитории с помощью агентной системы и хотят управлять решениями через явные checkpoints.

## Expected outcome

После прохождения flow в `.stepan/specs/<spec-id>/` хранится утверждённый, проревьюенный и трассируемый пакет с состоянием `stage: plan`, `status: approved`; работу можно корректно продолжить в новой сессии только по файлам репозитория.

## Scope

### In

- Provider-neutral pre-development flow, роли, переходы, агентное ревью и пользовательские checkpoints.
- Контракты артефактов, durable state, approvals, возвраты на предыдущие стадии, возобновление по файлам и границы записи ролей.
- Форма первого Codex adapter как repository overlay и критерии проверки его реализуемости.

### Out

- Реализация, тесты, code review и rework кода.
- Стадии после `stage: plan`, `status: approved`.
- Реализация adapters для Codex и других агентных систем до завершения концепции flow.
